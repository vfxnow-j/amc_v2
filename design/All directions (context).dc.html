Clusters as bubbles

One cluster is open at a time, the closing one collapses as the new one grows, and a cluster holding the current page keeps a quiet tint so you never lose your place. Same state drives light and dark so you can compare the two skins mid-interaction.

Turn 3 — soft / tiled, four takes, light + dark each

Fewer lines, more surface

Rules give way to surfaces: rounded tiles, generous radii, pill controls and breakout pods. Density is unchanged — same row heights and same field counts as 1a, just grouped by shape instead of by hairline. Each option is shown light then dark; every frame is the same dashboard so you can compare treatment, not content.

3a · Floating cards
Nav floats as a panel, content as separate cards on a tinted ground. Softest, most familiar.
3b · Bento tiles
One gap-gridded mosaic. Each tile owns a job and can be resized or reordered per role.
3c · Inset wells
One solid shell, content sunk into wells. Reads as an appliance — good for the desk.
